# Nazryx website — rules

Static HTML on Cloudflare Pages. Published folder: `site/` (Pages output directory = `site`). Functions live in `functions/`.

The full rebuild brief is `docs/NAZRYX_SITE_BRIEF.md`. It wins over anything below.
Pages are generated by `python3 tools/build.py` (writes site/*.html; output is committed, no build step on Cloudflare).
Shared styles: `site/assets/css/site.css`. Demos: `site/assets/js/{site,scan,story}.js`.

## Design
- One light, flat theme everywhere: bg #F6F4EF, cards #FFFFFF, ink #141414, brand blue #1259E6 only (tints #DCE8FD, #9DB9F2; flat KPI fills #D9F0E3, #FBE5D6).
- No gradients, glows, drop shadows, blur, pink or purple. The footer is the only dark band.
- Inter, self-hosted (400/500/600/700). Tabular figures for numbers.
- Motion only to explain or reveal data; transform/opacity only; respect prefers-reduced-motion.
- Mobile-first: no horizontal scroll at 360px; header fits one line at 390px.

## Copy
- Short, concrete, confident ("You make medicines. We run Kazakhstan."). No jargon unless it matters (keep EAEU).
- Facts only from section 1 of the brief; anything else gets a `<!-- TODO Omar: confirm -->` and stays off the page.
- Never publish client, principal, prospect or distributor names, fees or margins, addresses, or any legal entity name. Brand is "Nazryx" only.
- Molecule names only from the approved demo file `site/assets/data/kz_demo_molecules.json`; never add one without Omar's approval.
- Teams are in Lahore and on the ground in Almaty ("team on the ground", never "office"). Omar's title: Director, International Business.

## Security
- Never write any password, token or secret into the repo, code, comments, logs or previews. Secrets live only in Cloudflare (`wrangler pages secret put`).
- Only web files go in `site/`. Nothing private (spreadsheets, dumps, client files, notes) is ever committed.

## Workflow
- Work on a branch, share the Cloudflare preview URL, merge to main only with owner approval.
- Ask before anything destructive and before deploying to production.
